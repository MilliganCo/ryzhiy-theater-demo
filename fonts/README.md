# Self-hosted display fonts

The public site loads Alegreya from `alegreya.css`. The Cyrillic, Cyrillic Extended, Latin, and Latin Extended WOFF2 subsets retain their original Google Fonts character ranges. Use the variable weight axis for the title hierarchy. The three-font comparison is available under `review/typefaces/`.

| Family | Design source | Available weights | License |
| --- | --- | --- | --- |
| Alegreya | [Huerta Tipográfica / Alegreya](https://github.com/huertatipografica/Alegreya) | Variable 400–900 | SIL Open Font License 1.1 (`OFL-alegreya.txt`) |
| Podkova | [Cyreal / Podkova](https://github.com/cyrealtype/Podkova) | Variable 400–800 | SIL Open Font License 1.1 (`OFL-podkova.txt`) |
